## Step 0 — Read Everything Before Forming Any Opinion

Read all `PRD-*.md` files and `MVP-SCOPE.md` in full.

### Purpose

Understand the full context before making any design decisions. No opinions until you have read everything.

### Files to Read

| File           | Purpose                     |
| -------------- | --------------------------- |
| `PRD-*.md`     | All PRD files — read ALL    |
| `MVP-SCOPE.md` | Understand what is in scope |

### Output Format

After reading, produce:

```
=== PRD READING SUMMARY ===

What this system does (in plain language):
[2-3 sentences]

User roles I am designing for:
| Role | Primary goal | Frequency of use |

Modules and their relationship:
[How the modules connect — what flows between them]

Things I noticed that need UX attention:
[Gaps, ambiguities, or structural issues from a UX perspective]

Preliminary file structure:
[Rough mapping of screens to wireframe files]
```

### Then Proceed To

After producing the PRD Reading Summary, proceed to **Phase 1 — User Simulation**.

### Rule

Do not form opinions or make design decisions until Step 0 is complete.
